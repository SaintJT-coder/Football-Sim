# Gridiron GM — Franchise Sim

A standalone, responsive football franchise simulation reconstructed from Base44 screenshots.

## Play
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from a branch → main / root).

## Features
Dashboard, fantasy draft, scouting, draft board, roster management, front office upgrades, free agency, trades, salary cap, 18-week game simulation, standings, season awards, finances, league history, legends, and Hall of Fame.

## Saves
Progress is saved in browser localStorage. This is an independent reconstruction, not an export of Base44's original code or database. It does not transfer your existing franchise save.

## Development
No build process or dependencies. Edit `index.html` directly. Future versions should split the simulation engine, components, and styles into separate modules and add automated tests.
